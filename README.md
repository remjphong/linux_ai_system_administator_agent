# Linux AI Agent System Administrator

A safety-first Python agent for Linux system observation,
troubleshooting, and controlled administration.

## Current status

Initial project skeleton. Basic system checks and tool registry
are implemented. Automated tests cover registry behavior.

## Architecture

- Core: shared interfaces and result contracts.
- Tools: system observation and controlled operations.
- Policy: authorization and approval rules.
- Agent: orchestration and diagnosis.
- Audit: traceable records of decisions and actions.

## Requirements

- Python 3.11+
- Linux environment recommended for integration testing.

## Setup

Create and activate a virtual environment:

    python3 -m venv .venv
    source .venv/bin/activate

Install the project and development dependencies:

    python -m pip install --upgrade pip
    python -m pip install -e ".[dev]"

## Run

    linux-admin --check

Or:

    python -m linux_admin.main --check

## Test

    pytest -q

## Safety principles

- Observe before acting.
- Default to dry-run.
- Use allowlisted operations.
- Require approval for disruptive actions.
- Verify outcomes and record audit events.
- Never allow arbitrary shell commands generated by an LLM.
